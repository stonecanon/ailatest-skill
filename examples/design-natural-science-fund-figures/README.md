# 自然科学基金绘图 Skill 示意

这张示意图不再把 Skill 画成单纯的制图流程，而是展示自然科学基金图件应表达的科学论证关系：两个科学问题牵引三个研究内容块，每个内容块对应方法/证据层，最后汇入预期贡献。

示意内容为合成文字，不对应任何个人申请书或项目数据。配置与渲染脚本见 [`fund-figure-logic.json`](fund-figure-logic.json) 和 [`render_fund_figure_demo.py`](render_fund_figure_demo.py)。
