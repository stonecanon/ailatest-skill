# 自然科学基金写作 Skill 核心逻辑示意

这张示意图不再把写作 Skill 画成四个并列栏目，而是展示基金申请书的论证骨架：立项依据提出两个科学问题，三个研究内容分别展开对应的研究方案与证据，最后收束到科学贡献、应用边界和一句话服务目标。

示意内容为合成文字，不对应任何个人申请书、成果或项目数据。配置与渲染脚本见 [`proposal-core-logic.json`](proposal-core-logic.json) 和 [`render_proposal_argument_demo.py`](render_proposal_argument_demo.py)。
